ScienceResearch 技术栈教学手册

这份手册把“项目里有哪些技术、它们各自做什么、源码放在哪里、在项目中如何协作”讲成一堂可以按顺序阅读的入门课。它优化自《项目技术栈目录映射》，但更强调解释和源码走读。

文档日期：2026-09-15工程根：scienceresearch/project证据来源：仓库清单、源码、配置与治理记录

一条请求的旅程

先别记技术名词。把一次“打开课题工作台”的请求当成一条流水线，每个技术只负责一段。

  1. 浏览器地址用户访问 /contexts。
  2. Vue Router把 URL 映射到课题页面组件。
  3. TanStack Query发现需要课题数据，调用 service。
  4. API service + OpenAPI 类型用 fetch 调 /api/v1/contexts。
  5. Vite 或 Nginx开发期 Vite 代理；生产期 Nginx 转发到 API。
  6. Uvicorn + FastAPIHTTP 进入目标路由，DTO 校验输入。
  7. Application / Domain用例编排事务，业务规则框架无关。
  8. SQLAlchemy + psycopg仓储执行 SQL，驱动连接 PostgreSQL。
  9. 响应回到页面Query 更新缓存，Vue 渲染工作台。
  10. 未迁移路径FastAPI 未匹配时进入 Flask/SQLite 兼容桥。

↓

一句话理解双栈：目标是 FastAPI + PostgreSQL 的原生模块化单体；迁移期保留 Flask + SQLite 作为同源兼容层。新功能优先目标栈，旧路径不能突然失效。

学习地图

推荐按“入口 → 合同 → 业务 → 数据 → 前端 → 测试 → 部署”的顺序建立地图。

路径约定：完整仓库路径以 scienceresearch/project 开头。为避免每张卡片重复长前缀，后端卡片里的 api/、application/、domain/、adapters/ 默认位于 apps/api/src/scienceresearch/；前端卡片里的 main.ts、router/、features/、views/ 默认位于 apps/web/src/。
从哪里开始读，能看懂什么
学习阶段先看你会明白
1. 项目概况README.md、pyproject.toml、package.json项目定位、命令和依赖范围。
2. 后端入口apps/api/src/scienceresearch/main.pyFastAPI 如何组合路由、配置和兼容层。
3. API 合同api/routes/、api/dto/、packages/contracts/请求如何被校验并形成 OpenAPI 类型。
4. 业务和数据application/、domain/、adapters/persistence/业务规则、事务边界和 PostgreSQL 访问。
5. 前端结构main.ts、router/、features/、views/页面、路由和请求状态如何组织。
6. 验证apps/api/tests/、apps/web/tests/、tests/单元、契约、迁移和 E2E 各守什么关。
7. 运行docker-compose.yml、Dockerfile、Nginx、CI本地与隔离部署的完整拓扑。

后端与数据

这一组技术负责“接收请求、执行业务规则、可靠保存状态”。

基础运行时

Python 3.12

后端世界的“书写语言”

它是什么，干什么

Python 是编写本项目后端业务规则、API、脚本和测试的编程语言。可以把其他工具想象成灶台和锅，Python 则是写菜谱、判断火候的核心语言。

项目里承担什么

项目要求 Python 3.12+，使用类型标注、Pydantic、分层包结构和现代测试工具。

在对应文件夹中怎么实现
  • apps/api/src/scienceresearch/：后端包根，按 domain/application/adapters/api 分层。
  • apps/api/tests/：Python API 与仓储测试。
  • scripts/、database/scripts/、tests/：服务启动、迁移、治理和契约脚本。
  • pyproject.toml：声明 Python 版本、依赖和 pytest/mypy/ruff 配置。

学习提示：先读 pyproject.toml 了解依赖，再从 main.py 进入后端。

官方文档

目标后端

FastAPI

对外接待窗口与合同检查台

它是什么，干什么

FastAPI 是 Python Web API 框架，负责接收 HTTP 请求、校验输入、调用用例并返回 JSON/OpenAPI 文档。类比银行柜面：先检查表单，再交给后台处理。

项目里承担什么

目标 API 以 FastAPI 为组合根，优先匹配 /api/v1/*、/healthz、/readyz；未迁移路径再落到 Flask 兼容桥。

在对应文件夹中怎么实现
  • apps/api/src/scienceresearch/main.py：创建 FastAPI，安装错误处理、路由、CORS 和 WSGI 挂载。
  • api/routes/：健康检查、目录和课题路由。
  • api/errors.py：异常转稳定 JSON 错误。
  • application/、domain/：业务编排与规则，路由不复制业务。

学习提示：看 create_app()：先目标路由，再 legacy 挂载。

目标后端

Pydantic v2 / pydantic-settings

数据表格的验钞机

它是什么，干什么

Pydantic 把 API 输入输出变成有类型模型，自动检查字段、默认值和错误；pydantic-settings 从环境变量读取配置，避免密码或路径写死。

项目里承担什么

DTO 定义在 API 边界，Settings 定义环境、数据库 URL、artifact root 和日志级别。

在对应文件夹中怎么实现
  • api/dto/catalog.py、context.py、errors.py：请求/响应 DTO。
  • settings.py：BaseSettings 读取并校验配置。
  • apps/api/tests/test_target_settings_persistence.py 等覆盖边界。

学习提示：domain 不依赖 Pydantic；DTO 停在 API 边界。

SQLAlchemy 2

Python 对象与 SQL 的翻译官

它是什么，干什么

SQLAlchemy 是 ORM/数据库工具包，让 Python Repository/Session 操作对象，底层生成 SQL，同时管理事务、连接池和错误转换。

项目里承担什么

路由不持有 Session；事务由 Unit of Work 拥有，仓储通过 Session 读写。

在对应文件夹中怎么实现
  • adapters/persistence/session.py：Base、Engine、PostgresUnitOfWork、commit/rollback。
  • adapters/persistence/models.py：ORM 模型和 JSONB 映射。
  • adapters/persistence/context_repository.py：课题、工作流、成效卡仓储。

学习提示：看 PostgresUnitOfWork.session()：正常 commit，异常 rollback。

Alembic

数据库结构的版本控制

它是什么，干什么

Alembic 像数据库 schema 的 Git，把表结构变化写成迁移脚本，可重复升级到 head，避免手工改库。

项目里承担什么

PostgreSQL schema 的版本事实源在 migrations；Compose 先跑迁移，再启动 API。

在对应文件夹中怎么实现
  • database/migrations/alembic.ini：postgresql+psycopg 配置。
  • database/migrations/env.py：迁移运行环境。
  • database/migrations/versions/20260914_0001_postgres_baseline_v6.py：业务基线。
  • tests/migration/：迁移测试。

学习提示：命令：uv run alembic -c database/migrations/alembic.ini upgrade head。

psycopg 3

Python 与 PostgreSQL 的传话员

它是什么，干什么

psycopg 是 PostgreSQL 驱动。SQLAlchemy 生成 SQL，但真正连接、传参、取结果的是 psycopg。

项目里承担什么

在对应文件夹中怎么实现

学习提示：看到 postgresql+psycopg，就知道目标数据链路。

它是什么，干什么

Flask 3

旧业务的临时办公楼

它是什么，干什么

Flask 是旧系统 Web 框架。迁移期不是新功能首选，而是继续挂载尚未原生化的旧 API 和 DOM 兼容路径。

项目里承担什么

在对应文件夹中怎么实现

  • web.py、core.py：旧 HTTP/业务与 SQLite 内核。
  • adapters/legacy/、legacy_service.py：旧能力适配层。
  • main.py：PathPreservingWSGIMiddleware 挂载 /。

学习提示：新功能优先 FastAPI canonical /api/v1。

SQLite / sqlite3

一个文件就是一个小数据库

它是什么，干什么

SQLite 是嵌入式数据库，一个 .db 文件即可存数据。本项目用于旧业务和受控种子库，迁移脚本只读检查后可导入空 PostgreSQL。

项目里承担什么

在对应文件夹中怎么实现

  • core.py：sqlite3 连接和旧业务。

学习提示：导入脚本校验行数和哈希，不覆盖非空目标。

官方文档

常见问题

这些答案不追求百科式完整，只帮助你在本项目里做判断。

为什么同时有 FastAPI 和 Flask？

这是渐进迁移策略：FastAPI 承接目标 API 和新功能，Flask 保留旧路径避免迁移窗口功能失效。目标路由优先，未匹配路径才进入兼容桥。

为什么路由里不直接写 SQL？

路由负责协议转换；业务在 application/domain，数据访问在 persistence adapter。这样 API、事务和数据结构可以分别测试和演化。

前端为什么不能直接连数据库？

浏览器暴露数据库凭据且难以统一权限、事务、审计和错误处理。前端只调用同源 JSON API。

单测通过为什么还要 Playwright？

单测证明函数/组件正确；Playwright 证明真实浏览器里的路由、请求、DOM、Console 和用户路径可见结果正确。

为什么有 npm 和 uv 两套依赖工具？

JavaScript/Node 生态用 npm workspace，Python 生态用 uv。两者分别锁文件，保证前后端工具链可复现。

技术栈文档等于发布批准吗？

不等于。本文只说明仓库事实和实现方式；发布、正式验收和正式数据迁移需要用户明确授权与独立记录。
