# 目标栈运行与部署说明（2026-09-14）

## 范围

本文描述隔离环境的 FastAPI + PostgreSQL 16 + Alembic + Docker Compose + Nginx 运行方式，不表示正式数据迁移或发布已执行。

## 本地开发

```powershell
uv sync --locked --python 3.12
$env:SCIENCERESEARCH_DATABASE_URL='postgresql://user:password@localhost:5432/scienceresearch'
uv run alembic -c database/migrations/alembic.ini upgrade head
uv run python scripts/serve.py --runtime fastapi --port 8765
```

`scripts/serve.py --runtime flask` 仅为过渡调试入口；目标入口是 FastAPI，同源 DOM 兼容桥由挂载的 Flask WSGI adapter 承担，不使用 iframe。

## 隔离 Compose

```powershell
$env:POSTGRES_PASSWORD='仅本地隔离环境密码'
docker compose up --build
```

服务拓扑：

- `db`：PostgreSQL 16，持久卷 `postgres-data`
- `migrate`：一次性执行 Alembic `upgrade head`
- `api`：Uvicorn FastAPI，依赖迁移成功
- `web`：Nginx 提供现有 Vue dist，`/api`、`/healthz`、`/readyz` 反代 API

访问 `http://127.0.0.1:8765`。真实 PostgreSQL/Docker 不可用时，不声明集成验证通过。

## 数据和回滚边界

- Alembic `0001_postgres_baseline_v6` 只用于空 PostgreSQL 隔离库。
- 不把正式 SQLite 挂载到目标服务，不执行正式导入。
- 隔离演练失败时删除 Compose 卷并重建；生产回滚必须先停写、备份和执行反向导出校验，另获用户授权。
- downgrade 仅面向隔离环境；生产禁止用它放弃数据。

## 健康检查

- `/healthz`：进程存活，不查数据库。
- `/readyz`：数据库 ping 和 Alembic 版本；失败返回 503。
