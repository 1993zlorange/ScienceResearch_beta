# 技术手册运行期资产构建工具 API 说明

## 1. 工具身份

- 脚本：`scripts/build_technical_manuals.py`
- 配置：`config/technical-manuals.json`
- 输出：`apps/web/public/generated/technical-docs/`
- 文档日期：2026-09-17
- 维护人：全栈工程师、项目测试

## 2. 目的

将三份正式技术手册源文件构建为同源、离线、可哈希校验的运行期 HTML 和 `manifest.json`，供 `/technical-docs` 页面读取。工具不修改正式手册源文件，不访问网络，不读取机器绝对路径。

## 3. 命令行接口

```powershell
python scripts/build_technical_manuals.py --project-root . [--config config/technical-manuals.json] [--check]
```

| 参数 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `--project-root` | 否 | 当前目录 | `scienceresearch/project` 工程根；建议显式传入 |
| `--config` | 否 | `config/technical-manuals.json` | 相对工程根的构建配置 |
| `--check` | 否 | 不启用 | 只校验源文件与既有输出，不写入 |

## 4. 输入配置合同

`config/technical-manuals.json` 包含：

- `version`：非空版本，当前 `20260917.v1`；
- `output_root`：只允许工程内 `apps/web/public/generated/technical-docs`；
- `manuals[]`：每个条目含 `id`、`title`、`description`、`source`、`version`、`output_filename`、`sha256`；
- `source` 只允许 `docs/...` 或 `../achieve/04-交付与阶段/...`，不得逃逸仓库根；
- `output_filename` 必须是安全文件名，不能包含路径。

## 5. 输出

- 三份 HTML：源文件字节级复制；
- `manifest.json`：包含版本、生成日期、手册标题、描述、来源相对路径、URL、字节数和 SHA-256；
- 控制台输出 JSON：`{"status":"OK","manuals":3,"mode":"build"}` 或 `mode":"check"`。

## 6. 退出码和错误

| 退出码 | 含义 | 处置 |
|---|---:|---|
| 0 | 构建或检查成功 | 可继续前端构建 |
| 1 | 配置无效、源缺失、哈希不匹配、路径越界或既有输出过期 | 修正正式源和配置后重跑 |

错误只输出到 `stderr`，不输出绝对路径、秘密或源文件内容。

## 7. 安全与幂等

- 源哈希必须与配置完全一致；
- 输出路径必须位于工程根内；
- 重复运行覆盖同名生成物，不改变正式源；
- 构建产物由 `.gitignore` 排除，可随时重建；
- `--check` 用于发布前确认输出未漂移。

## 8. 验证示例

```powershell
python scripts/build_technical_manuals.py --project-root .
python scripts/build_technical_manuals.py --project-root . --check
```

最小验收为两条命令均退出 0，且 `manifest.json` 包含三份手册。
